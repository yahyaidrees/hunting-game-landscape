# Farmer of the Jungle

This is the relaunch of the hunting game: a farm-and-hunt game for Android, built in Unity 6.3 LTS with URP.

- **Game plan:** [Docs/GamePlan/Hunting-Game-Relaunch-Plan.md](Docs/GamePlan/Hunting-Game-Relaunch-Plan.md)
- **Decisions:** [Docs/DecisionsLog.md](Docs/DecisionsLog.md)
- **Old project inventory:** [Docs/OldProjectInventory.md](Docs/OldProjectInventory.md)
- **Licence log:** [Assets/_Game/Data/Credits/LicenceLog.csv](Assets/_Game/Data/Credits/LicenceLog.csv)

## Layout
| Folder | Holds |
|---|---|
| `Assets/_Game/` | Everything made for the game: Scripts, Art, Animation, Audio, Data, Prefabs, Scenes |
| `Assets/_Incoming/OldGame/` | Staging for old Built-in assets, before the quality gate |
| `Assets/ThirdParty/` | Outside assets, one folder each, each logged in the licence log |
| `SourceAssets/` | Blender files, raw downloads, generated images and sounds (LFS, not imported) |
| `Docs/` | Plan, decisions, inventory |
| `Tools/` | Blender scripts |

Clone with Git LFS installed (`git lfs install`). Use the editor version in `ProjectSettings/ProjectVersion.txt`.
